# การดูแลและข้อจำกัด

- ข่าว Google ค้นหา `when:7d`; Bing เป็น fallback เมื่อ Google ใช้ไม่ได้และกรองย้อนหลัง 7 วันเมื่ออ่านวันที่ได้ ไม่ใช่หลักประกันว่าพบทุกโพสต์หรือทันทีที่เผยแพร่
- `SiPH` อาจตรงกับความหมายอื่น ควรปรับคำค้นและตรวจความเกี่ยวข้องในบริบทจริง รายการคำค้นเป็น OR ไม่ได้บังคับว่าต้องมีทั้ง SiPH และคำว่าโรงพยาบาล
- Sentiment เป็น lexicon บวก/ลบ/กลาง ภาษาไทย/อังกฤษ มีคำปฏิเสธบางรูปแบบ ไม่เข้าใจการประชด บริบทการรักษา หรือข้อเท็จจริงครบถ้วน ข้อความที่มีทั้งบวก/ลบเป็นกลางเพื่อให้ทีมงานตรวจต่อ ไม่ใช่ความแม่นยำที่วัดบนชุดข้อมูลผู้ป่วย
- แก้หมวดและสถานะได้ แต่ไม่สร้าง notification ย้อนหลังเมื่อเปลี่ยนหมวดหรือเมื่อเพิ่งเปิดช่องทาง
- คิวใหม่สร้างเฉพาะช่องทางและหมวดที่เปิดตอนพบข่าว, unique `(article_id, channel)`, retry 5 ครั้งพร้อม backoff ปุ่ม retry นำรายการ failed กลับเข้า pending โดยใช้ idempotency key เดิม ระยะรับประกันกันซ้ำขึ้นกับ Resend/LINE และโควตาบัญชี ไม่ใช่ exactly-once delivery
- ปิดช่องทางหยุดส่งคิวช่องทางนั้นชั่วคราว แต่เปิดกลับแล้วอาจส่งคิวเดิมที่ค้างอยู่ “พักการตรวจอัตโนมัติ” หยุด collector เท่านั้น ไม่หยุดคิวแจ้งเตือนที่อนุญาตไว้
- D1 lease locks กัน scan/delivery ซ้อนกัน 4 นาที ขนาดงานถูกจำกัด และหลัง process ล้มเหลว lock จะหมดอายุให้รอบถัดไปทำต่อได้ ไม่ใช่ distributed transaction กับ API ภายนอก
- รอบค้นหาที่ล้มเหลวบันทึกไว้แล้วรอรอบถัดไป; ผู้ดูแลกดตรวจใหม่ได้ การปิดเครื่อง/พลาด trigger ไม่ย้อนรันทุกชั่วโมงที่ขาด แต่ตรวจ slot ปัจจุบัน
- Dashboard แสดงข่าวล่าสุดไม่เกิน 1,000 รายการ, runs ล่าสุด 30 รายการ, delivery ล่าสุด 50 รายการ; ตัวเลขรวมมาจากทุกข่าวใน D1 CSV ส่งออกสูงสุด 10,000 ข่าว เก็บข่าวต่อเนื่องจนกว่าผู้ดูแลวางนโยบาย retention/สำรองผ่าน PR
- ติดตาม Workers/D1/API usage และค่าใช้บริการจากแต่ละผู้ให้บริการ ไม่มีการเปลี่ยน plan หรือสมัครบริการส่งข้อความในงานพัฒนา
- อย่า log Secrets, headers Authorization, response bodies ของ social provider หรือ one-use setup link ลง GitHub/issue/logs ห้ามเปิด production auth bypass เพื่อทดสอบ ใช้ฐานทดสอบและ credentials จำลอง
- หลัง merge ให้ smoke-test เวอร์ชันที่ Deploy จริง (login, RSS, provider API และผู้รับที่อนุญาต) ก่อนเปิดช่องทางจริง ชุดทดสอบในเครื่องไม่แทนการตรวจบัญชีและโควตาจริง
